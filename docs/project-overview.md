# Project Overview

This Active Directory project simulates a small enterprise environment using Windows Server 2022 and Windows 11 virtual machines.

It was designed to demonstrate real-world IT administration skills including domain creation, DNS configuration, user management, and authentication troubleshooting.

---

## Environment

- DC01: Windows Server 2022 Domain Controller
- CLIENT01: Windows 11 domain-joined workstation
- Domain: paullab.local

---

## Core Functions

- Active Directory Domain Services
- DNS resolution for domain authentication
- User and group management
- Shared folder access control
